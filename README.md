# DataStraw – Smart Roster Management System

## About the Project

This project is made to manage employee shifts and create monthly work schedules. It helps manage employees, leaves, holidays, weekly offs and shift allocation from one place.

The main purpose of this project is to make roster management easier and reduce manual work.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Axios

## Features

- Add, edit and delete employees.
- Manage employee teams.
- Apply for leave and manage leave requests.
- Add and manage public holidays.
- Set weekly offs for employees.
- Create roster rules based on brand and process.
- Generate monthly rosters automatically.
- Allocate Morning, Evening and Night shifts.
- Check roster conflicts and staffing requirements.
- Get backup employee suggestions.
- Edit employee shift assignments.

## Project Setup

First, open the frontend folder in the terminal.

Install the required packages:

```bash
npm install
```

Start the application:

```bash
npm run dev
```

After running the command, open the local URL shown in the terminal.

## Backend

The backend is developed using Node.js and Express.js. MongoDB is used for storing employee and roster data.

Backend API:

https://datastaw-roster.onrender.com/api
